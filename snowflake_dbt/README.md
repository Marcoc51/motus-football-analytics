# Historical Snowflake dbt project

This directory contains the original Brentford project's dbt configuration and SQL models for its Snowflake warehouse. It is preserved as historical implementation; its current operation has not been verified. The planned Motus PostgreSQL warehouse will require separate transformation work.

The project was initialized using [dbt's starter-project tooling](https://docs.getdbt.com/reference/commands/init). This README replaces the generic starter instructions with project-specific context. The SQL models have not been changed as part of the licensing work.
