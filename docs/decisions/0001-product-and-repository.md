# 0001: Product and repository

Status: Accepted direction; implementation pending.

## Decision

- Evolve this repository into the independent, open-source Motus Football Analytics platform while retaining its Git history and original Brentford project files.
- Keep this public product's codebase and roadmap separate from the commercial Motus product. The co-founders have approved use of the Motus brand identity.
- Start with Brentford and design for a future team-selection interface and additional clubs.
- State explicitly that the project is not affiliated with or endorsed by Brentford FC.

## Rationale

Retaining the repository preserves attribution and the original work. A separate public roadmap gives contributors an honest view of what exists and what is planned. A team-aware direction avoids presenting Brentford-specific assumptions as permanent product rules.

## Alternatives considered

The original Brentford-only project and a new repository were possible paths. The selected path retains the existing repository and history while changing its product direction.

## Open questions

- What is the first useful Brentford release and how will team selection behave before another club is supported?
- What contribution and release policies are needed as the project grows?
- Which historical assets can be shared publicly under their applicable rights?
